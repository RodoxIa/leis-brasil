# Espelho — Leis do Brasil

Este repositório é um **espelho** de [`ctresb/leis`](https://github.com/ctresb/leis),
que reúne todas as leis do Brasil (federais, estaduais, municipais, tratados,
jurisprudência e atos de reguladores), uma norma por commit.

- **Fonte original:** https://github.com/ctresb/leis
- **O que é este repo:** cópia de backup, mantida por RodoxIa/FuturizeIA.
- **Atualização:** automática, 2x por semana (terça e sexta), puxando o upstream
  e republicando aqui. A documentação e os arquivos do projeto original ficam
  preservados (ver `README.md`).

Todo o crédito do acervo é do projeto original `ctresb/leis`. Este espelho existe
apenas para garantir uma cópia própria e disponível.
